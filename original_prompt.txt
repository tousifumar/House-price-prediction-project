# HOUSE PRICE PREDICTOR — COMPLETE FULL-STACK DEVELOPMENT PROMPT

## 1. PROJECT OVERVIEW

Build a complete, production-ready web application called:

# "House Price Predictor"

The application is an AI/ML-powered real-estate property valuation platform.

The primary purpose of the application is to allow users to enter detailed property information and receive an estimated market price using a trained Machine Learning model.

The system should not behave like a simple ML demo. Build it as a complete SaaS-style real-estate platform with:

* Modern responsive frontend
* User authentication
* Property price prediction
* Machine Learning API
* Prediction history
* Property comparison
* Market analytics
* Location/locality analysis
* Saved properties
* Price alerts
* PDF valuation reports
* Admin dashboard
* Dataset management
* ML model management
* Model performance analytics
* REST APIs
* Proper database architecture
* Secure authentication and authorization

The application must be modular, scalable, maintainable and production-ready.

# 3. HIGH-LEVEL ARCHITECTURE

Implement the following architecture:

User
↓
Laravel Frontend
↓
Laravel Backend/API
↓
Validation + Feature Preparation
↓
Python FastAPI ML Service
↓
Trained ML Model
↓
Prediction
↓
Laravel
↓
Prediction Result Dashboard

Architecture:

```
                HOUSE PRICE PREDICTOR
                        |
          ┌─────────────┴─────────────┐
          |                           |
     Laravel App                 Python ML
          |                       Service
          |                           |
   ┌──────┴──────┐             ┌──────┴──────┐
   |             |             |             |
 MySQL         REST API     ML Model      Analytics
   |             |             |
   └─────────────┴─────────────┘
```

Keep the ML service independent from Laravel so the model can be retrained or replaced without changing the main application.
